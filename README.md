## Interactive Web GIS Dashboard

The interactive web dashboard is published via GitHub Pages:
👉 **[Launch Live Web Dashboard](https://rindelk.github.io/canadian-rockies-expedition/)**

### Dashboard Features:
* **True Highway Geometries**: Over 51,000 OSRM road-snapped coordinate points ensuring zero straight-line GPS drift.
* **Dual-Unit Standard**: All statistics, stage cards, timeline intervals, and fuel metrics presented in dual **`[miles] mi ([kilometers] km)`**.
* **Responsive Split-View**: Desktop drag-to-resize pane divider (`#resizer-gutter`) with preset ratio toggles (`65% Map`, `50/50`, `65% Feed`).
* **Native Mobile App Architecture (`<= 850px`)**: Dedicated full-screen views with a persistent bottom navigation bar (`Map`, `Itinerary`, `Timeline`, `Files`, `Notes`), sticky quick-day jumper (`Day 1`–`Day 18`), and horizontal swipeable category chips tray.
* **Interactive Saddle Timeline & Gantt Chart**: Dual-view switcher featuring thumb-friendly mobile daily schedule cards and a desktop horizontal grid with freeze-pane pinned stage labels.
* **In-App Trip Notes & AI Fine-Tuning Studio**: Offline browser storage (`localStorage`), 1-tap **📋 Copy Prompt for AI** button formatting field notes into prompt instructions for Antigravity AI, and 1-tap **📥 Export .md**.
* **Multi-Layer Basemaps**: Dark Canvas, Topographic Contour, and High-Resolution Satellite imagery powered by keyless Esri tile services.
